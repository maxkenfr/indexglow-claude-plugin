# IndexGlow plugin for Claude

The [IndexGlow](https://indexglow.com) plugin for claude.ai, Cowork and Claude Code: your Google Search Console and Bing Webmaster Tools data in a conversation with Claude. The plugin itself is in [`indexglow/`](indexglow/), with its own README.

This repository is generated from IndexGlow's source: open issues at https://indexglow.com/support.

## Claude Code

```sh
claude plugin marketplace add maxkenfr/indexglow-claude-plugin
claude plugin install indexglow@indexglow
```

Then `/mcp` connects IndexGlow with a browser sign-in.

## claude.ai and Cowork

Add the plugin from Customize > Plugins, then connect IndexGlow from its Connectors tab.
